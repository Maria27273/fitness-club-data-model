# Бизнес-правила и ограничения

## Связи между сущностями

### Клиент – Абонемент
- У каждого клиента может быть только один активный абонемент
- Один абонемент принадлежит ровно одному клиенту

### Клиент – Запись
- Один клиент может иметь много записей на занятия
- Каждая запись относится ровно к одному клиенту

### Тренер – Занятие
- Один тренер может проводить много занятий
- Каждое занятие ведет ровно один тренер

### Занятие – Запись
- На одно занятие может быть много записей
- Каждая запись относится ровно к одному занятию

---

## Ограничения целостности

### 1. Один активный абонемент на клиента
- У клиента может быть только один активный абонемент одновременно
- В таблице Абонементы для каждого client_id допускается не больше одной строки со статусом 'активен'

### 2. Запись только с активным абонементом
- Клиент может записаться на занятие только при наличии активного абонемента
- Для каждой записи должен существовать активный абонемент с тем же client_id

### 3. Ограничение по количеству участников
- На занятие не может записаться больше людей, чем указано в max_participants
- Для каждого занятия количество записей со статусом 'подтверждена' не может превышать max_participants

### 4. Одно занятие в одно время
- Клиент не может быть записан на два занятия, которые проходят одновременно
- Нельзя иметь две записи с пересекающимися интервалами времени

### 5. Тренер не может вести два занятия одновременно
- Для каждого тренера занятия не должны пересекаться по времени

### 6. Уникальность записей
- Одна и та же пара (клиент, занятие) не должна повторяться в активных записях
- Клиент не может иметь две активные записи на одно и то же занятие

---

## Бизнес-логика

### 7. Автоматическое обновление статуса абонемента
- При наступлении end_date статус абонемента автоматически меняется на 'закончен'
- Абонемент типа 'разовый' автоматически становится 'закончен' после посещения одного занятия

### 8. Возрастное ограничение
- Клиент должен быть старше 14 лет для самостоятельных занятий
- birth_date должен быть как минимум на 14 лет раньше текущей даты

### 9. Удаление данных с сохранением истории
- Нельзя удалить клиента, если у него есть записи на будущие занятия
- Нельзя удалить тренера, если у него есть запланированные занятия
- Нельзя удалить занятие, если на него есть подтвержденные записи
