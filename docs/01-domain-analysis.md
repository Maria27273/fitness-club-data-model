# Анализ предметной области

## Описание предметной области
Фитнес-клуб предоставляет услуги по посещению индивидуальных и групповых тренировок.
Занятия проводятся тренерами в соответствии с расписанием. Для каждого занятия определяются тип, время проведения, продолжительность и максимально допустимое количество участников. В процессе работы клуба также отслеживаются сроки действия абонементов, статусы записей и состояние используемого оборудования.

В рамках предметной области рассматриваются следующие процессы:

* регистрация и ведение данных о клиентах;
* оформление и учёт абонементов;
* формирование расписания занятий;
* запись клиентов на занятия;
* контроль количества участников;
* учёт проведённых и запланированных занятий;
* учёт состояния тренажёров;
* контроль сроков действия абонементов.


## Границы предметной области

В рамках проекта рассматриваются:

* хранение и актуализация данных, необходимых для работы фитнес-клуба;
* управление абонементами;
* планирование занятий;
* запись клиентов;
* контроль ограничений предметной области;
* учёт состояния оборудования;

В проект не входят:

* проведение и обработка платежей;
* расчёт заработной платы сотрудников;
* закупка оборудования;
* управление поставщиками;
* мобильное приложение;
* интеграция с внешними информационными системами.
