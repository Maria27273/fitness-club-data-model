# Бизнес-правила

**BR-01**

Клиент может иметь несколько абонементов за весь период обслуживания, но одновременно может иметь не более одного активного абонемента.

**BR-02**

Дата окончания абонемента не может быть раньше даты его начала.

**BR-03**

После окончания срока действия абонемент должен переходить в статус «закончен».

**BR-04**

Разовый абонемент становится неактивным после использования предоставленного посещения.


**BR-05**

Клиент может записаться на занятие только при наличии действующего абонемента.

**BR-06**

Количество подтверждённых записей на занятие не может превышать установленное максимальное количество участников.

**BR-07**

Клиент не может иметь более одной активной записи на одно занятие.

**BR-08**

Клиент не может быть одновременно записан на занятия, временные интервалы которых пересекаются.


**BR-09**

Тренер не может проводить два занятия, временные интервалы которых пересекаются.


**BR-10**

Для самостоятельного посещения занятий клиент должен быть старше 14 лет.


**BR-11**

Клиент не может быть удалён при наличии записей на будущие занятия.

**BR-12**

Тренер не может быть удалён при наличии запланированных занятий.

**BR-13**

Занятие не может быть удалено при наличии подтверждённых записей.
