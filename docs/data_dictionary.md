# Словарь данных

## 1. Клиенты

Хранит информацию о клиентах фитнес-клуба.

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| client_id | SERIAL (PK) | Идентификатор клиента |
| name | VARCHAR(100) | Имя клиента |
| phone | VARCHAR(20) | Телефон |
| email | VARCHAR(100) | Электронная почта |
| birth_date | DATE | Дата рождения |
| registration_date | DATE | Дата регистрации |

---

## 2. Тренеры

Хранит информацию о тренерах.

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| trainer_id | SERIAL (PK) | Идентификатор тренера |
| name | VARCHAR(100) | Имя тренера |
| specialization | VARCHAR(50) | Специализация |
| experience_years | INTEGER | Стаж работы (лет) |

---

## 3. Занятия

Хранит информацию о занятиях.

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| session_id | SERIAL (PK) | Идентификатор занятия |
| trainer_id | INTEGER (FK → Тренеры) | Идентификатор тренера |
| type | VARCHAR(50) | Тип занятия |
| start_time | TIMESTAMP | Время начала |
| duration_minutes | INTEGER | Продолжительность (мин) |
| max_participants | INTEGER | Максимальное количество участников |

---

## 4. Абонементы

Хранит информацию об абонементах клиентов.

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| membership_id | SERIAL (PK) | Идентификатор абонемента |
| client_id | INTEGER (FK → Клиенты) | Идентификатор клиента |
| type | VARCHAR(20) | Тип абонемента (разовый/месячный/годовой) |
| start_date | DATE | Дата начала |
| end_date | DATE | Дата окончания |
| status | VARCHAR(20) | Статус (активен/закончен/заблокирован) |

---

## 5. Записи на занятия

Хранит информацию о записях клиентов на занятия.

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| booking_id | SERIAL (PK) | Идентификатор записи |
| client_id | INTEGER (FK → Клиенты) | Идентификатор клиента |
| session_id | INTEGER (FK → Занятия) | Идентификатор занятия |
| booking_date | TIMESTAMP | Дата и время записи |
| status | VARCHAR(20) | Статус (подтверждена/отменена/состоялась/неявка) |

---

## 6. Тренажеры

Хранит информацию о тренажерах в клубе.

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| equipment_id | SERIAL (PK) | Идентификатор тренажера |
| name | VARCHAR(100) | Название тренажера |
| type | VARCHAR(20) | Тип (кардио/силовое) |
| status | VARCHAR(20) | Статус (доступен/занят/обслуживание) |
| last_maintenance | DATE | Дата последнего обслуживания |
