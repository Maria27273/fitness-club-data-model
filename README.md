# Модель данных для управления фитнес-клубом

 Проект по системному анализу и проектированию реляционной базы данных для автоматизации работы фитнес-клуба.

## О проекте

**Бизнес-контекст:**  
В фитнес-клубе существуют проблемы с двойной записью клиентов на одно время, отсутствием контроля за истекающими абонементами и перегрузкой некоторых тренеров. Менеджеры тратят до 2 часов в день на ручную сверку расписания.

**Цель проекта:**  
Разработать структуру данных, которая автоматизирует:
- Контроль свободных мест на занятиях;
- Проверку активного статуса абонемента при записи;
- Предотвращение пересечения времени у тренеров;
- Формирование аналитических отчетов для руководства.
